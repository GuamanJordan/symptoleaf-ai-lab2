## Abrir y revisar el editable

1. Abrir diagrams.net y seleccionar **Archivo → Abrir desde → Dispositivo**.
2. Elegir el archivo `.drawio` de esta carpeta.
3. Comprobar actores, casos de uso y relaciones frente a la Tarea 3 y las referencias RF/CU de las historias.
4. Guardar cualquier corrección en una rama y solicitar revisión mediante PR.

El XML del editable se comprobó al preparar el aporte; la revisión visual y semántica del modelo debe completarse con Denise. El alcance de este aporte se limita a la documentación académica y al diagrama editable indicado; no incorpora el código ni el historial del proyecto base.

## Mantenimiento

Si cambia la Tarea 3, actualizar en el mismo PR la copia de esta carpeta y la conservada en `docs/02-requisitos/`, o consolidar la ubicación y corregir todos los enlaces afectados. Registrar los cambios de requisitos o casos de uso en las historias relacionadas.
