# SymptoLeaf-AI — Laboratorio del proceso del equipo

Repositorio académico del laboratorio de Construcción y Evolución de Software, NRC 36848.

El equipo está integrado por Jordan Guaman, Denise Rea y Mesias Mariscal. El proyecto base es SymptoLeaf-AI, una aplicación de diagnóstico de enfermedades en plantas.

El equipo organiza el trabajo en GitHub Projects. Cada cambio se desarrolla en una rama vinculada a un issue y se integra mediante un pull request revisado.

Documentación del curso: [inicio](docs/01-inicio/) y [requisitos](docs/02-requisitos/), incorporados mediante pull requests del equipo.

## Flujo de trabajo

- Organizar tareas e iteraciones en GitHub Projects.
- Vincular cada rama y pull request con un issue.
- Usar la [plantilla de pull request](.github/PULL_REQUEST_TEMPLATE.md) y solicitar revisión de otro integrante.
- Consultar la [guía de configuración del Project](docs/01-inicio/github-project.md).
